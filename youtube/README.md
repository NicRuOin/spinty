# YouTube-Studio (Gaming Shorts)

Pipeline mit 4 Rollen:
- **Analyse:** findet Trends und wertet die eigenen Zahlen aus (YouTube Data API, kommt noch)
- **Regie:** Konzept + Szenenplan pro Episode (`<episode>/docs/shotlist.md`)
- **Builder:** baut das Video im Code (three.js-Figuren, synthetische Musik/SFX), Render in 1080×1920 / 60 fps
- **Prüfer:** Kontaktbögen + Bewertungsrunden (`<episode>/docs/critique.md`), Copyright-/Richtlinien-Check

Upload erst nach Freigabe durch den Kanalinhaber.

Episoden: `ep01-bonk/`. Die Figur „Bix“ lebt in `ep01-bonk/sets/bix.js`.
